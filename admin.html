How to create the access token (administrator)
  1. Sign in to GitHub, click your profile picture, then Settings.
  2. Open Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it “Careers admin”, set an expiry (for example 90 days).
  4. Under Repository access choose Only select repositories and pick shilton-careers.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it and give it to the HR team member. Each person should use their own token.

How to add a job
  1. Click + Add job, fill in the details and click Save job.
  2. To remove a job from the website, click Close next to it. Click Reopen to bring it back.
  3. When you are finished, click Save to website. Your changes go live in 1 to 2 minutes.
